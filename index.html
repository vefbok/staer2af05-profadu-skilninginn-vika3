Verkefni 1

(−3a2)2 · a3
Einfaldaðu stæðuna.
Taktu stuðulinn og veldið af a fyrir hvort í sínu lagi. Skoðaðu síðan veldin með sama stofni.

Lausn til samanburðar

(−3a²)² = (−3)² · a⁴ = 9a⁴.

9a⁴ · a³ = 9a⁷.

Verkefni 2

Skref 1 af 3 · Veldu rétta liðun
(x + s)(x + t) = ?
Margfaldaðu fyrst x með báðum liðum seinni svigans og gerðu svo það sama fyrir s.
Skref 2 af 3 · Þáttaðu x-liðina.
x² + sx + tx + st
Hvaða þátt eiga sx og tx sameiginlegan? Hvað stendur eftir þegar hann er tekinn út fyrir sviga?
Skref 3 af 3 · Berðu saman við almenna formið og veldu rétt samband
x² + (s + t)x + st
og
x² + bx + c
Berðu saman töluna fyrir framan x í stæðunum og síðan liðinn sem inniheldur ekkert x.

Lausn til samanburðar

1. Margföldum úr svigum:
(x + s)(x + t) = x² + sx + tx + st

2. Tökum x út fyrir sviga:
sx + tx = (s + t)x, svo (x + s)(x + t) = x² + (s + t)x + st.

3. Berum saman við:
x² + bx + c
Þá fæst b = s + t og c = st.

Verkefni 3

Hvað hlýtur að gilda þegar margfeldið er núll?
Prófaðu x = 2 og x = −3. Berðu saman þættina tvo þegar margfeldið er núll.

Lausn til samanburðar

Ef (x − 2)(x + 3) = 0 þá er x − 2 = 0 eða x + 3 = 0.

Lausnirnar eru x = 2 og x = −3. Með því að deila með x − 2 er gildið x = 2 útilokað og lausnin tapast.

Verkefni 4

x2 + 4x = 21
Skref 1 af 3 · Veldu staðalform jöfnunnar. Staðalform er ax² + bx + c = 0, þar sem a ≠ 0.
Dragðu 21 frá báðum hliðum. Leitaðu að tölum með summuna 4 og margfeldið −21.
Skref 2 af 3 · Veldu þáttun x² + 4x − 21.
Dragðu 21 frá báðum hliðum. Leitaðu að tölum með summuna 4 og margfeldið −21.
Skref 3 af 3 · Veldu lausnamengið fyrir (x + 7)(x − 3) = 0.
Dragðu 21 frá báðum hliðum. Leitaðu að tölum með summuna 4 og margfeldið −21.

Lausn til samanburðar

x² + 4x − 21 = 0.

(x + 7)(x − 3) = 0.

Þá er x + 7 = 0 eða x − 3 = 0. Lausnamengið er {−7, 3}.

Verkefni 5

Rannsakaðu jöfnurnar og finndu út hversu margar lausnir þær hafa.

x² = 9Ólokið

Hversu margar lausnir hefur jafnan x² = 9?
x² = 9

Hugsaðu um hvaða tölur gefa gildið hægra megin þegar þær eru margfaldaðar með sjálfum sér.
Hversu margar lausnir hefur jafnan x² = 0?
x² = 0

Hugsaðu um hvaða tölur gefa gildið hægra megin þegar þær eru margfaldaðar með sjálfum sér.
Hversu margar rauntölulausnir hefur jafnan x² = −9?
x² = −9

Hugsaðu um hvaða tölur gefa gildið hægra megin þegar þær eru margfaldaðar með sjálfum sér.
Hversu margar lausnir hefur jafnan x² = c?
SkilyrðiFjöldi lausna
Berðu saman jákvætt gildi, núll og neikvætt gildi á hægri hlið.

Þegar c > 0 má leysa jöfnuna x² = c með ferningsrótaraðferð:

x = ±c

Til dæmis: x² = 9, svo x = ±9 og því x = −3 eða x = 3. Táknið ± stendur fyrir bæði jákvæðu og neikvæðu lausnina.

Lausn til samanburðar

Ef c > 0 eru tvær lausnir: x = ±√c. Til dæmis gefur x² = 9 lausnirnar x = −3 og x = 3.

Ef c = 0 er eina lausnin x = 0.

Ef c < 0 er engin rauntölulausn, því x² ≥ 0 fyrir allar rauntölur.
