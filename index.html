Verkefni 1

(−3a2)2 · a3
Einfaldaðu stæðuna.
Taktu stuðulinn og veldið af a fyrir hvort í sínu lagi. Skoðaðu síðan veldin með sama stofni.

Lausn til samanburðar

(−3a²)² = (−3)² · a⁴ = 9a⁴.

9a⁴ · a³ = 9a⁷.

Verkefni 2

Skref 1 af 3 · Veldu rétta liðun
(x + s)(x + t) = ?
Margfaldaðu fyrst x með báðum liðum seinni svigans og gerðu svo það sama fyrir s.
Skref 2 af 3 · Þáttaðu x-liðina.
x² + sx + tx + st
Hvaða þátt eiga sx og tx sameiginlegan? Hvað stendur eftir þegar hann er tekinn út fyrir sviga?
Skref 3 af 3 · Berðu saman við almenna formið og veldu rétt samband
x² + (s + t)x + st
og
x² + bx + c
Berðu saman töluna fyrir framan x í stæðunum og síðan liðinn sem inniheldur ekkert x.

Lausn til samanburðar

1. Margföldum úr svigum:
(x + s)(x + t) = x² + sx + tx + st

2. Tökum x út fyrir sviga:
sx + tx = (s + t)x, svo (x + s)(x + t) = x² + (s + t)x + st.

3. Berum saman við:
x² + bx + c
Þá fæst b = s + t og c = st.

Verkefni 3

Hvað hlýtur að gilda þegar margfeldið er núll?
Prófaðu x = 2 og x = −3. Berðu saman þættina tvo þegar margfeldið er núll.

Lausn til samanburðar

Ef (x − 2)(x + 3) = 0 þá er x − 2 = 0 eða x + 3 = 0.

Lausnirnar eru x = 2 og x = −3. Með því að deila með x − 2 er gildið x = 2 útilokað og lausnin tapast.

Verkefni 4

x2 + 4x = 21
Skref 1 af 3 · Veldu staðalform jöfnunnar. Staðalform er ax² + bx + c = 0, þar sem a ≠ 0.
Dragðu 21 frá báðum hliðum. Leitaðu að tölum með summuna 4 og margfeldið −21.
Skref 2 af 3 · Veldu þáttun x² + 4x − 21.
Dragðu 21 frá báðum hliðum. Leitaðu að tölum með summuna 4 og margfeldið −21.
Skref 3 af 3 · Veldu lausnamengið fyrir (x + 7)(x − 3) = 0.
Dragðu 21 frá báðum hliðum. Leitaðu að tölum með summuna 4 og margfeldið −21.

Lausn til samanburðar

x² + 4x − 21 = 0.

(x + 7)(x − 3) = 0.

Þá er x + 7 = 0 eða x − 3 = 0. Lausnamengið er {−7, 3}.

Verkefni 5

A · Hvers vegna fást tvær lausnir?

x² = 9

Færðu sleðann og finndu tölurnar sem gefa 9 þegar þær eru settar í annað veldi.

x = −3 eða x = 3

Skref 1

x² = 9

Skref 2

Tökum ferningsrót beggja vegna: x2 = 9. Þar sem x2 = |x| fæst |x| = 3. Tölugildi x er 3, það er fjarlægðin frá núlli.

Skref 3

x = −3 eða x = 3. Rótaraðferðin gefur sömu tvær lausnir og sleðinn. Táknið ± sýnir bæði formerkin.

x = ±9 = ±3

Hvers vegna fást tvær lausnir við x² = 9?
Skoðaðu hvað gerist þegar tala er margfölduð með sjálfri sér.

B · Hvers vegna fæst stundum engin lausn?

x² = −9

Færðu sleðann og reyndu að finna tölu sem gefur −9 þegar hún er sett í annað veldi.

Prófaðu neikvætt gildi, núll og jákvætt gildi. Prófgildin hjálpa þér að sjá mynstrið. Til að svara þarftu reglu sem gildir fyrir allar tölur.

Hvers vegna hefur jafnan x² = −9 enga lausn?
Skoðaðu hvað gerist þegar tala er margfölduð með sjálfri sér.

Fjöldi lausna

JafnaFjöldi lausna
x² = 92
x² = 01
x² = −90

x² = a hefur tvær lausnir ef a > 0, eina lausn ef a = 0 og enga lausn ef a < 0. Þegar a = 0 er x = 0 eina lausnin, því aðeins núll gefur núll í öðru veldi.

Lausn til samanburðar

Jafnan x² = 9 jafngildir |x| = 3. Tölurnar −3 og 3 eru báðar í fjarlægð 3 frá núlli.

Ef x² = 0 er x = 0 eina lausnin. Núll hefur ekkert annað formerki.

Ferningur er alltaf jákvæður eða núll. Þess vegna hefur x² = −9 enga lausn.
